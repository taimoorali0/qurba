# Quran fonts

Both files are shipped exactly as received (no conversion or subsetting).

| File | Font | Author | Notes |
|---|---|---|---|
| `al-mushaf-quran.ttf` | Al_Mushaf (Sept 2008) | Amjad Hussain Alvi, Alvi Technologies, Peshawar — http://www.alvitechnologies.com | Default Quran font (Indo-Pak style). The file carries no licence text and restricts embedding (fsType 4): written permission from Alvi Technologies is needed before public release. |
| `kfgqpc-uthmanic-hafs.otf` | KFGQPC Uthmanic Script HAFS v0.09 | King Fahd Glorious Quran Printing Complex | "Madinah" option in the reader. Free to use, copy and distribute unmodified — see `KFGQPC-LICENSE.txt`. |
| `jameel-noori-nastaleeq.woff2` | Jameel Noori Nastaleeq v1 (2008) | "Urdu Lover" | Urdu text. Font says "This Font Is Free Of Charge For Urdu Lovers". Lossless WOFF2 of the supplied TTF (glyphs unchanged); loaded only for Arabic-script characters on Urdu pages. |

English and UI text use Inter (SIL Open Font License) from npm `@fontsource/inter`.
